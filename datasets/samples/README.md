# Jeux d'exemples

`stories.json` reprend, sous forme structurée, des récits **fictifs** déjà présents dans les prototypes HTML. Ils servent de matière aux futurs tests NLP et data.

Ils ne sont pas chargés dans PostgreSQL au démarrage. L'application reste vide de récits tant qu'un compte n'en dépose pas.

Ces fichiers ne contiennent ni score, ni indicateur de confiance, ni résultat d'extraction.
