# Frontend

Interface React de la phase 1. Les appels partent vers `/api`, que Vite relaie vers le backend.

```powershell
npm install
npm run dev
npm test
npm run lint
npm run build
```

L'application est sur <http://localhost:5173>. Le backend doit être joignable sur le port 8000, sauf si `VITE_PROXY_TARGET` indique une autre adresse.
