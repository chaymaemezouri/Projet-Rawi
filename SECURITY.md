# Sécurité

Pour signaler une faille, ouvrez une issue privée auprès des mainteneurs ou écrivez dans la discussion d'équipe. Ne publiez pas de secret, de jeton ou de donnée de récit dans une issue publique.

Le détail des contrôles de la phase 1 est dans [security-devops/SECURITY.md](security-devops/SECURITY.md).

Les identifiants de `.env.example` et de `docker-compose.yml` ne valent que pour une base locale. Ils ne doivent pas être réutilisés sur un serveur partagé.
